# Polygenic Risk Scores: Concepts to Reproducible Analysis

This course contains 20 separate Rmd chapters, practical code, scientific figures generated by R, references in every chapter, and an end-to-end synthetic analysis. No Quarto is required.

## Start here

1. Extract the complete ZIP. Keep its directories together.
2. Open the extracted directory as an RStudio project, or set it as the working directory.
3. Read COURSE_PLAN.md and DATA_STRATEGY.md.
4. Install `rmarkdown` and `knitr` in R if needed: `install.packages(c("rmarkdown", "knitr"))`.
5. Open a chapter and Knit. To render everything from the course root, run `Rscript scripts/render_course.R` in the Terminal.
6. Run `Rscript scripts/run_analysis.R` for the complete fixed-score synthetic analysis. It creates a new directory and refuses to overwrite an existing run.

Knitting requires R and Pandoc (normally supplied with RStudio). R code blocks are not Terminal commands. Markdown links are not R code. Rendered chapters write figures in their relative `figures/` paths. Upload both generated Markdown and images for GitHub display.

## What is supplied and what is not

The 20 Rmd sources and shared scripts are complete source deliverables. This build environment has no R executable. No knitted Markdown, R-generated figure output, PLINK output or posterior method output is claimed to have been executed here. Consult VERIFICATION.md for checks performed and remaining gates.

Core practicals require no external data downloads. Method chapters identify optional packages and reference resources separately. External-software examples are disabled during knitting. The synthetic data are not real patient data and cannot support clinical claims.

## Project continuity

Chapters 1–7 use explicit, self-contained foundational examples. Chapters 8–20 use `scripts/course_helpers.R` where appropriate. The shared simulation is independent of those earlier mini-exercises. It uses 120 fictional variants and 11,000 fictional people with fixed roles. Methods are taught separately; the final analysis does not select a winner using final test outcomes.

The final model uses age, SBP and a fixed synthetic PRS. It is not a validated clinical CAD calculator. The source helper discloses the generating mechanism for teaching; do not use hidden truth as fitted weights or tuning evidence.

## GitHub

`index.Rmd` knits to `index.md`. Links are intended for GitHub Pages paths built from the Markdown files. Viewing raw repository Markdown may require `.md` suffixes instead. Styling depends on your Pages configuration; this package does not deploy a site or add a rendering framework. Do not overwrite a working `_config.yml` without reviewing its settings.
